# Vitis
Es una billetera electrónica que, frente a la multiplicidad de billeteras actuales, esta diseñada para centralizar tus cuentas y permitirte registrar ingresos y egresos externos a las instituciones financieras. Además, te ayuda a definir y cumplir metas de ahorro para que mantengas un control total sobre tus finanzas en un solo lugar.

## Características Principales
* Centralización Bancaria: Integra tus plataformas bancarias y financieras en una única vista.
* Gestión Manual de Movimientos: Asentá ingresos y egresos fuera del sistema bancario tradicional.
* Metas de Ahorro: Establece objetivos financieros personalizados y realizá un seguimiento de tu progreso.
* Control Presupuestario: Analizá el flujo histórico y actual de tus fondos con claridad.
